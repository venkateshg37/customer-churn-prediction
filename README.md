# Customer Churn Prediction
Built a machine learning-based Customer Churn Prediction system using classification algorithms, deployed with FastAPI backend and Streamlit frontend to provide real-time predictions and improve customer retention strategies.

## 📌 Overview
This project predicts whether a customer is likely to churn (leave a service) using machine learning. It helps businesses take proactive steps to retain customers.

## 🚀 Features
- Real-time churn prediction
- FastAPI backend for model serving
- Streamlit UI for user interaction
- End-to-end ML pipeline

## 🧠 Model
- Algorithm: Random Forest Classifier
- Includes preprocessing and feature encoding

## 🛠 Tech Stack
- Python
- scikit-learn
- FastAPI
- Streamlit
- Pandas, NumPy


## 📊 Output
- Predicts whether customer will churn or not
